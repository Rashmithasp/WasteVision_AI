# One-hour hackathon plan

0–10 min: Extract ZIP, create virtual environment, install requirements.
10–25 min: Launch app and verify model download and inference.
25–40 min: Improve visual design and add examples or category explanations.
40–50 min: Test with 3–5 different waste images and record results.
50–60 min: Capture screenshots and prepare 1-minute demo pitch.

## Problem
Waste is often improperly segregated due to confusion about materials.

## Solution
A photo-based AI assistant that predicts a likely waste category and gives sorting tips.

## Limitations
Zero-shot CLIP can misclassify unusual or composite objects; categories are estimates and sorting rules differ by municipality.

## Future scope
Municipality-specific rules, camera capture, multilingual guidance, detection of multiple objects, and a trained waste-specific model.
